WORKERS DEV · LIVE WALKTHROUGH

A Worker, in front of
your app — see it run

This is the shape of what we build for you: a single Worker that handles the request, applies security inline, and returns in milliseconds. Send a request below and watch it move through the pipeline.

worker.js deployed · 330+ cities 
// Runs at the edge, in front of your origin
export default {
  async fetch(request, env) {
    // 1 · security applied inline
    const verdict = await inspect(request, {
      waf: true,       // OWASP + custom
      rateLimit: 100,  // req / min / IP
      botManagement: true,
    });

    if (verdict.blocked) {
      return new Response("Blocked at edge", {
        status: 403,
      });
    }

    // 2 · read/write edge data (no origin trip)
    const cached = await env.KV.get(request.url);
    if (cached) return new Response(cached);

    // 3 · only clean traffic reaches origin
    return fetch(request);
  }
}

Cloudflare is a connectivity cloud platform that combines networking, application performance, and security services on a single global network. It helps organizations accelerate websites and applications while protecting them with integrated capabilities such as CDN, DDoS protection, Web Application Firewall (WAF), Zero Trust, and SASE solutions.
Cloudflare One is Cloudflare's SASE platform that unifies networking and security through a single control plane. It includes Zero Trust Network Access (ZTNA), Secure Web Gateway (SWG), Cloud Access Security Broker (CASB), Data Loss Prevention (DLP), Browser Isolation, Cloudflare Tunnel, and Digital Experience Monitoring to secure users, devices, and applications from anywhere.
Traditional security relies on multiple on-premises appliances such as firewalls, VPN concentrators, and web gateways. Cloudflare delivers these capabilities from its globally distributed cloud network, reducing infrastructure complexity while providing consistent security policies, lower latency, and simplified management.
Cloudflare Zero Trust verifies every user, device, and request before granting access to applications. Instead of extending the corporate network through VPNs, it provides identity-aware, least-privilege access while continuously enforcing security policies based on user identity, device posture, and context.
Cloudflare protects websites using multiple security layers including Web Application Firewall (WAF), DDoS mitigation, Bot Management, rate limiting, SSL/TLS encryption, DNS security, and threat intelligence. These services inspect and filter malicious traffic before it reaches the origin infrastructure.
Cloudflare Magic Transit is a cloud-native network protection service that safeguards on-premises, cloud, and hybrid networks against Layer 3 and Layer 4 DDoS attacks. It uses Cloudflare's global Anycast network to absorb and mitigate attacks close to their source while accelerating legitimate traffic.
